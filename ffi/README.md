# lib3mf-ffi

C/C++ FFI bindings for [lib3mf](https://github.com/telecos/lib3mf_rust), a pure Rust implementation for reading and writing 3MF (3D Manufacturing Format) files.

## Building

```bash
cd ffi
cargo build --release
```

This produces:
- A **shared library** (`liblib3mf_ffi.so` / `lib3mf_ffi.dll` / `liblib3mf_ffi.dylib`)
- A **static library** (`liblib3mf_ffi.a` / `lib3mf_ffi.lib`)
- A **C/C++ header** (`include/lib3mf_ffi.h`) – auto-generated by [cbindgen](https://github.com/mozilla/cbindgen)

## Usage from C/C++

Include the generated header and link against the library:

```c
#include "lib3mf_ffi.h"

int main(void) {
    Lib3mfModel *model = NULL;
    Lib3mfResult result = lib3mf_model_read_file("model.3mf", &model);
    if (result != Ok) {
        printf("Error: %s\n", lib3mf_get_last_error());
        return 1;
    }

    uint32_t object_count = 0;
    lib3mf_model_get_object_count(model, &object_count);
    printf("Objects: %u\n", object_count);

    for (uint32_t i = 0; i < object_count; i++) {
        uint32_t vertex_count = 0, triangle_count = 0;
        lib3mf_model_get_object_vertex_count(model, i, &vertex_count);
        lib3mf_model_get_object_triangle_count(model, i, &triangle_count);
        printf("  Object %u: %u vertices, %u triangles\n", i, vertex_count, triangle_count);
    }

    lib3mf_model_destroy(model);
    return 0;
}
```

### Linking

**Linux/macOS:**
```bash
gcc -o example example.c -L target/release -llib3mf_ffi -lpthread -ldl -lm
```

**Windows (MSVC):**
```cmd
cl example.c /I include /link lib3mf_ffi.dll.lib
```

## API Overview

### Error Handling

All functions return `Lib3mfResult`. On failure, call `lib3mf_get_last_error()` for a descriptive message.

| Code | Name | Description |
|------|------|-------------|
| 0 | `Ok` | Success |
| 1 | `ErrorNullPointer` | Null pointer argument |
| 2 | `ErrorIo` | I/O error (file not found, etc.) |
| 3 | `ErrorParse` | 3MF parsing error |
| 4 | `ErrorIndexOutOfBounds` | Index out of bounds |
| 5 | `ErrorInvalidArg` | Invalid argument |
| 6 | `ErrorInternal` | Internal error |

### Model Lifecycle

| Function | Description |
|----------|-------------|
| `lib3mf_model_create` | Create a new empty model |
| `lib3mf_model_read_file` | Read a 3MF file from disk |
| `lib3mf_model_write_file` | Write model to a 3MF file |
| `lib3mf_model_destroy` | Free a model handle |

### Model Queries

| Function | Description |
|----------|-------------|
| `lib3mf_model_get_unit` | Get the model's unit string |
| `lib3mf_model_get_metadata_count` | Get number of metadata entries |
| `lib3mf_model_get_metadata` | Get metadata name/value by index |

### Object Queries

| Function | Description |
|----------|-------------|
| `lib3mf_model_get_object_count` | Get number of objects |
| `lib3mf_model_get_object_id` | Get object ID by index |
| `lib3mf_model_get_object_name` | Get object name by index |

### Mesh Data

| Function | Description |
|----------|-------------|
| `lib3mf_model_get_object_vertex_count` | Get vertex count |
| `lib3mf_model_get_object_triangle_count` | Get triangle count |
| `lib3mf_model_get_object_vertex` | Get a vertex (x, y, z) |
| `lib3mf_model_get_object_triangle` | Get a triangle (v1, v2, v3) |

### Build Items

| Function | Description |
|----------|-------------|
| `lib3mf_model_get_build_item_count` | Get number of build items |
| `lib3mf_model_get_build_item_object_id` | Get build item's object ID |
| `lib3mf_model_get_build_item_transform` | Get build item's 4×3 transform |

## Thread Safety

Each thread maintains its own error state. String pointers returned by query functions are valid only until the next FFI call on the same thread.

## Memory Management

- Model handles must be freed with `lib3mf_model_destroy`.
- Passing `NULL` to `lib3mf_model_destroy` is a safe no-op.
- String pointers are temporary and should be copied if needed beyond the next FFI call.
